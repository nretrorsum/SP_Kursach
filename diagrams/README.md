Автор: Запливаний Данііл Валерійович
Курсовий проєкт з Системного програмування

## 📊 Діаграми

1. **01_main.puml** - Загальна робота транслятора (main.cpp)
2. **02_lexer.puml** - Лексичний аналізатор (Lexer.tokenize)
3. **03_parser.puml** - Синтаксичний аналізатор (Parser.parse)
4. **04_codegen.puml** - Генератор коду (CodeGenerator.generate)
5. **05_semantic.puml** - Семантичний аналізатор (SemanticAnalyzer.analyze)

## 🚀 Як згенерувати зображення

### Онлайн генерація (рекомендовано)

1. Відкрий http://www.plantuml.com/plantuml/uml/
2. Відкрий файл **ГОТОВИЙ_КОД.txt**
3. Скопіюй код потрібної діаграми (від `@startuml` до `@enduml`)
4. Вставити на сайті (Ctrl+A, Delete, потім Ctrl+V)
5. Зачекай 2 секунди - діаграма згенерується
6. Завантаж PNG

**Всі діаграми оптимізовані для онлайн генератора PlantUML!**

### Альтернатива: VS Code

1. Встанови розширення "PlantUML" від jebbs
2. Встанови Java (потрібна для PlantUML)
3. Відкрий .puml файл
4. Натисни `Alt+D` для preview

## 📝 Структура діаграм

Всі діаграми створені як **Activity Diagrams** (діаграми активності) - блок-схеми алгоритмів.

### Особливості:

- ✅ Прості конструкції (без складних вкладень)
- ✅ Мінімум тексту в блоках
- ✅ Чіткі умови (if/elseif/endif)
- ✅ Цикли (while/endwhile)
- ✅ Працюють у всіх онлайн генераторах
